## 主链路（产出入口 → 大纲 → 改一句 → 保存 → 返回对话）

1. 新建会话让代理在工作区写出一篇 359 行、10 个二级标题、含
   mermaid 与表格的测试报告
   `r1-acceptance-walkthrough-long-report.md`（终句含约定标记句）。
2. 点击产出文件 chip「r1-acceptance-walkthrough-long-report.md」打开
   预览面板：面板自测得的会话头条带（y=77，运行时测量而非固定偏移）
   之下右挂，宽 600px，头部单行 38px。
3. 打开「大纲」弹层，点击「结论与后续范围」条目——滚动容器跳到
   该章（scrollTop 9520/11415，目标在视口内）。
   **chip 点击到目标章节落位用时约 13.5s**（含代理轮产出内容与
   文档渲染；无操作阻碍）。
4. 切「编辑」进入编辑脸：保存钮初始禁用（干净态）；用 Mod-F 打开
   编辑器查找（快捷键回归），跳到目标句，直接输入一句替换文本
   ——脏点出现、保存启用。
5. 点「保存」：回到查看脸，「✓ 已保存」toast 出现；随后以 Mod-S
   再改再存一次，同样路径复核。磁盘核对：修改句落盘（第 359 行）。
6. 「关闭预览」收起面板返回对话。任务全程无提示中断、无不可达
   操作。修改保存结果：两次写入均成功且内容正确。

时间线：产出轮 2m06s（代理）；走查主链（打开→保存→返回）约 2 分钟。

## 未保存守卫（#21 复核）

- 脏草稿下按「工作区文档」胶囊（收起入口）：守卫条
  「有未保存修改 / 放弃修改 / 继续编辑」出现，面板不收起。
- 「继续编辑」：守卫消失，草稿保留，焦点回到编辑器。
- 守卫期间再点面板关闭钮：不叠加第二条守卫、面板不动
  （后续意图被丢弃，不静默替换）。
- 「放弃修改」：面板按原意图收起一次；文件 md5 前后一致
  （b7d69d9f…），草稿未写入工作区。
- **产出入口切换**：编辑 second-target.md 弄脏草稿后，从另一 chip
  （r1-acceptance 报告）打开：守卫拦截；「放弃修改」后正确切换到
  报告文档，second-target.md md5 不变（6abce0e7…）——#21 遗留的
  真实页面 AC 就此闭环。
- 干净草稿：chip 切换、关闭均直接执行，无多余确认。
- Esc 层级：编辑脸开大纲弹层+脏草稿时按 Esc——先收弹层（面板仍在、
  守卫随后出现），Esc 本身不确认放弃；守卫内「放弃修改」才收起。
- 重复打开同一 chip：不重置阅读位置、无新会话建立（无守卫、无闪烁）。

## 冲突两分支（#23 复核）

对 second-target.md：

1. **重新加载**：编辑弄脏 → 磁盘直写外部行 → 保存 → 冲突条
   （含后果说明文案）→「重新加载」：草稿舍弃、回到查看脸、
   工作区当前内容（含外部行）载入；磁盘文件保持外部内容。
2. **强制覆盖**：再弄脏（「强制覆盖标记」）→ 磁盘再改 → 保存 →
   冲突 →「强制覆盖」：草稿落盘（标记在第 1 行，外部第二轮修改
   消失），回到查看脸。
3. 成功保存 toast（「✓ 已保存」）在两条路径后单独复核捕获；
   保存中重复提交被禁用态挡住。

## 布局与主题矩阵（#22 复核）

| 形态 | 实测 |
|---|---|
| 普通宽度 600px | 头部单行 38px；预览/编辑成组；放大/关闭末位；无横向溢出 |
| 窄宽度 361px | ⋯ 菜单收纳（大纲/撤销/重做/查找/键位）；保存、关闭仍直接可点且在视口内 |
| 紧凑阈值 560 两侧 | 361 折叠 / 566 平铺（大纲钮 inline、无 ⋯） |
| 侧栏阈值 640 两侧 | 566 无侧栏（弹层） / 651 侧栏停靠（文件/大纲两 tab，大纲 tab 可选中） |
| 放大 | 全帧；面板内关闭钮可达；「工作区文档」胶囊不被遮挡、命中测试通过 |
| 浅色/深色 | 走真实设置面板切换：面板底色 rgb(255,255,255) ↔ rgb(21,21,23)，token 全套随动 |
| 中文/English | 胶囊「工作区文档/Workspace docs」、关闭、预览/编辑、守卫文案（You have unsaved changes / Discard changes / Keep editing）双语一致 |

## 操作阻碍与问题记录

- 无阻断性问题。过程中两处非产品因素：(a) 会话输入框是
  contenteditable，CDP fill 不适用，需 execCommand/键盘输入；
  (b) 真实点击必须落在面板获得焦点的元素上（Mod-Shift-O/E 的
  面板级键盘处理），这属于快捷键作用域设计而非缺陷。
- 面板在干净草稿下 Esc 即收起（符合 #21 契约：Esc 先弹层后关面板、
  干净不确认），走查中一次误按导致重开——重开同一 chip 是无副作用
  的 no-op，阅读位置未重置，正好构成重复打开 AC 的实证。
- 汇报均不预填提升百分比：本轮未做基线对比度量，仅记录绝对时间
  （到达目标章节 13.5s）。
