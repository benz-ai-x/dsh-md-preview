# v0.10.0 — 文档侧边栏与阅读体验更新

预览面板现在可以在宽屏与对话并排停靠。会话头部的回形针打开工作区文档，面板
右上 × 关闭；未保存修改仍先确认，关闭后焦点返回入口。

相对 npm 上一版 v0.7.2，本次发布包含：

- **文档侧边栏**：宽屏预留独立空间，窄屏和全屏时覆盖展开；保留宽度记忆，
  原生导航和工具详情继续可用，关闭及卸载恢复宿主布局。
- **UI 与排版**：统一导航字体、间距和原生图标，完善浅/深主题与键盘焦点；
  正文沿用 Harness 的 Markdown 字号、行距与段落节奏。
- **查找文档**：按名称搜索整个工作区，包括未展开目录；新增当前回合产出、
  最近阅读和继续阅读入口，明确区分空结果、不完整结果与失败。
- **阅读连续性**：重新打开恢复阅读位置，记忆面板及导航偏好；按打开意图安排
  文档与导航空间，保留手动选择。
- **编辑可靠性**：关闭、换文档及切回预览统一经过未保存守卫；保存反馈和冲突
  处理更清晰，过期请求不会覆盖后续文档。

兼容固定的 DeepSeek Harness `0.1.2-rc.1` 基线。

```sh
dsh plugin --profile web add @benz-ai-x/dsh-md-preview@0.10.0
```

验证：`pnpm verify` 通过 123 项基线检查、290 项测试、类型检查和构建检查。
同一发布 tarball 在干净 profile 完成安装、普通包名导入、启动、资源服务和移除
验证；启动图 47 → 46，资源 HTTP 200 → 404，SIGTERM 退出码均为 0。

侧边栏适配依赖固定基线的布局结构，升级 Harness 需复验；用户上传的文档附件
仍不支持预览。顶栏对齐等下一轮优化及主题/缩放的剩余视觉验收继续在 #36、#37
跟踪。验证证据见 [发布验证](../verification/releases/v0.10.0/WALKTHROUGH.md)。
