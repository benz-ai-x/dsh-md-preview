# ADR-0007：Markdown 使用官方右栏标签

日期：2026-09-09。状态：已实施，真实浏览器验收由 #60 跟踪。
替代 [ADR-0004](0004-dock-preview-beside-the-harness-frame.md) 的独立停靠适配。

## 决定

按用户确认的 #54 → #55 → #56 → #59 → #60 迁移 Markdown 预览和编辑。
官方右栏负责资源身份、标签、分栏、浮动、布局与关闭；插件只提供 Markdown 文档类型、
正文、编辑和受控文件访问。官方树、聊天提及、工具路径、产出 chip 使用同一资源入口。
保留消息级预览文档动作，退出 turnTail 接管、独立树、header toggle、旧 overlay 和 frame 样式。
root overlay 仅保留平台未保存确认 Modal。

草稿归存活标签记录，不归易于重挂载的正文组件。切换/隐藏保留草稿、光标及撤销历史，
真正删除记录才取消工作并释放；数据不持久化。Host 继续裁决路径、版本、字节与写权限，
成功写入向官方文件观察通道发布事实。

原生 API 缺少关闭前否决能力，因此先在独立 Harness worktree 补
`sidebarRight.beforeClose(sessionId, tabId, guard)`。守卫位于布局删除提交前，覆盖实际删除
记录的所有路径；不截获 DOM 点击、不回插已删除标签，也不伪造未保存状态到官方服务。
保存中关闭先等待保存。取消或插件卸载后，迟到授权不能删除后继记录。

## 兼容与取舍

固定 Harness 0.1.5-alpha.1 的本地补丁提交见 lock；官方同版本 npm 尚不含此能力。
缺少接口时明确拒绝激活并回滚 Remote。补丁单独保存供上游评审，不修改用户原检出。

文件名搜索、独立大纲/持久阅读、通用文本及其他格式后置。旧阅读数据保留，但宽度偏好
不映射到官方布局。预览行导航定位所属 ATX 章节；精确源行定位由编辑器提供。
无法完整读取的超限文档只能转官方只读查看，不允许用截断内容进入编辑。

## 验证

公开服务与 Slot 装配测试覆盖原生打开、编辑/保存、撤销重做、查找、冲突、保存后读失败、
标签切换、会话隔离、迟到结果、守卫、卸载和变化提示；Host 测试验证文件权威。
完整 verify、真实浏览器及同归档安装证据见
[本轮记录](../verification/official-sidebar-markdown/TDD.md)。旧版290项测试与旧截图保留为历史，
已退役控件的测试不作为新版可用性依据。#60 未完成的检查不由自动化结果替代。
