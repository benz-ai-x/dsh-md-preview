# 受守卫的写入复用 fs 服务的版本令牌做乐观锁

面板保存需要"文件自我读取后未被别方改动"的守卫。我们不自造 mtime+size 之类的
指纹格式,而是把 fs 服务 `stat` 返回的不透明 `FsVersion` 原样作为「指纹」交给
浏览器,保存时经 `writeText` 的 `replaceIfVersion` 守卫原子校验,过期映射为
`md-preview/conflict`;`force` 即省略守卫条件。复用令牌让校验留在后端原子路径上
(含符号链接规范化复检),自造格式则只能在宿主侧非原子地比一比。

## Considered Options

- 自造指纹(mtimeMs:size 或内容哈希):可脱离后端实现,但非原子、且与后端自身
  的写守卫语义平行存在,迟早分叉。
- 复用 `FsVersion`(选定):一次令牌、一条守卫路径,浏览器侧完全不解释令牌内容。
