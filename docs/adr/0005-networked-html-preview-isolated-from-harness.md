# HTML 预览允许常规联网并与 Harness 隔离

日期：2026-09-08。状态：已接受的设计边界，尚未实现；具体嵌入方案待定。

用户要求 HTML 预览具有内嵌浏览器的页面体验，并确认允许页面常规联网。
因此 HTML 预览支持页面样式与 JavaScript 交互，默认允许加载 CDN 脚本、在线字体
等外部资源及请求外部 API，遵守浏览器自身的同源与跨域规则。预览页面与 Harness
的界面和会话数据保持隔离，工作区文件访问继续由 Host 与文件服务裁决。

本轮以本地 HTML 文件为入口，只读预览，不提供 HTML 编辑或保存；开发网站和
任意网址的直接打开入口留待后续阶段。入口范围不改变页面常规联网的已决边界。

本地关联文件允许与 HTML 分处同一会话工作区的不同目录，以支持共享样式、脚本、
图片和数据；例如 `reports/index.html` 可以引用 `../assets/app.js` 及
`../data/result.json`。资源路径解析后仍须处于该工作区，文件范围判断归 Host
与文件服务。

HTML 链接导航按目标处理：同一会话工作区内的 HTML 在预览面板中打开，目标
读取仍须经 Host 与文件服务裁决；外部网站在浏览器新标签页打开，面板保留当前
本地 HTML。链接导航规则不改变页面加载外部资源和请求 API 的已决联网边界。

同一次预览期间，本地文件在外部被改动时，由读者通过面板“刷新”执行内容刷新，
重新载入当前 HTML 页面；面板不因文件变化自动重载，页面交互状态保留到刷新前。
这不改变页面自身脚本与常规联网交互的已决范围。

## 取舍

允许脚本和常规联网能覆盖依赖外部库及在线数据的报告、原型；默认禁用脚本或联网
会限制这些页面的完整体验。相应地，预览依赖网络与远端服务的可用性，API 响应能否
被页面读取仍取决于浏览器跨域规则与服务端策略。浏览器允许加载部分跨域资源，
并通过同源策略限制跨页面访问，见 [MDN 同源策略](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)。

隔离是实现必须满足的边界，不能仅凭开启一个内嵌页面就认定完成。
HTML 标准对内嵌页面脚本、同源权限及资源来源有明确约束，具体方案需据此验证，
见 [HTML sandbox 规范](https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox)。
关联文件的具体服务接线及脚本导航的浏览器验证留在实施阶段；已确认需求、待定
技术选择与本轮范围见 [Spec #38](https://github.com/benz-ai-x/dsh-md-preview/issues/38)。
这份 ADR 记录用户已确认的边界，具体实现仍须提供隔离与资源访问的验证证据。
